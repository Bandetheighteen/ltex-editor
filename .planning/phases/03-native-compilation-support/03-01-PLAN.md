# Plan: 03-01 (Implement compile_latex Tauri command and async process handling)

## Objective
Implement a Tauri command in Rust to asynchronously spawn `pdflatex` as a child process. This replaces the old Node.js `child_process` logic, avoiding the previous hanging process issues.

## Tasks
1. **Add `serde` and `tempfile` dependencies**:
   - Update `src-tauri/Cargo.toml` to include `serde = { version = "1.0", features = ["derive"] }` and `tempfile = "3"`.
2. **Implement `compile_latex` Tauri Command**:
   - In `src-tauri/src/main.rs`, create a `#[tauri::command] async fn compile_latex(code: String) -> Result<CompileResponse, String>`.
   - The function should:
     - Create a temporary directory using `tempfile::tempdir()`.
     - Write the `code` to a `document.tex` file inside the temporary directory.
     - Spawn `pdflatex` using `std::process::Command`, with arguments `-interaction=nonstopmode`, `-halt-on-error`, and `-output-directory=<temp_dir>`.
     - Wait for the process to finish.
3. **Define Response Structs**:
   - Define a `CompileResponse` struct that derives `Serialize`. It should include `pdf_buffer: Option<Vec<u8>>` and `log: Option<String>`.
4. **Register the Command**:
   - Update the `tauri::Builder::default()` call in `main` to `.invoke_handler(tauri::generate_handler![compile_latex])`.
