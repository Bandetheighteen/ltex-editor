# Plan: 02-01 (Initialize Tauri v2 project and configure tauri.conf.json)

## Objective
Initialize the Rust Tauri v2 project inside the current repository and configure it to serve the existing vanilla web frontend located in `public/`.

## Tasks

1. **Install Tauri CLI and Initialize Project**:
   - Run `npm install -D @tauri-apps/cli@next` (or latest v2) to get the CLI.
   - Run `npx tauri init` with appropriate arguments to create the `src-tauri` directory.
   - App name: `LaTeX Editor`
   - Window title: `LaTeX Editor`
   - Frontend Dist: `../public`
   - Dev URL: `../public` (Since we don't have a dev server, we point to the public folder directly)
2. **Configure `tauri.conf.json`**:
   - Verify that `build.devUrl` and `build.frontendDist` are correctly set to `../public`.
   - Update identifier to `com.latex.editor`.
3. **Verify Dependencies**:
   - Check `package.json` to ensure Tauri CLI is listed in `devDependencies`.
   - Check `src-tauri/Cargo.toml` to ensure the Tauri dependencies are correctly pointing to v2 APIs.
