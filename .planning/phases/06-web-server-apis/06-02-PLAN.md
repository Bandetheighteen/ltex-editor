# Plan: 06-02 (Implement POST /api/synctex logic)

## Objective
Add the `/api/synctex` endpoint to resolve PDF coordinates back to source code lines via the `synctex` CLI.

## Tasks
1. **Implement Endpoint**:
   - Add `app.post('/api/synctex', async (req, res) => { ... })` in `server.js`.
   - Destructure `page`, `x`, `y` from `req.body`.
   - Target the persistent temp directory used by `/api/compile`.
   - Ensure `document.pdf` exists in that directory. If not, return `{ line: null }`.
   - Spawn `synctex edit -o <page>:<x>:<y>:<pdf_path>`.
2. **Parse Output**:
   - Extract the line starting with `Line:` from the standard output.
   - Return `{ line: <number> }` as a JSON response.
3. **Verify API Match**:
   - Make sure the response structure exactly matches what `backend-adapter.js` expects (`{ line: X }`).
