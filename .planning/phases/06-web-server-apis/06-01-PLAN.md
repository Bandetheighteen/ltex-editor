# Plan: 06-01 (Implement POST /api/compile with timeout and cleanup)

## Objective
Add the `/api/compile` endpoint to the Node server to securely compile LaTeX code into a PDF, mimicking the Rust implementation.

## Tasks
1. **Dependencies**:
   - `fs` and `child_process` (built-in).
2. **Implement Endpoint**:
   - Add `app.post('/api/compile', async (req, res) => { ... })` in `server.js`.
   - The endpoint will create a dedicated temporary workspace directory (e.g. `os.tmpdir() + '/latex-editor-web-workspace'`) so the `.synctex.gz` file is preserved across requests.
   - Write `req.body.code` to `document.tex`.
   - Use `child_process.spawn` or `execFile` to run `pdflatex -synctex=1 -interaction=nonstopmode -halt-on-error -output-directory=... document.tex`.
   - Wrap the execution in a Promise with a strict 10-second timeout. If it exceeds 10s, kill the process to prevent zombies.
   - Wait for the process to complete.
3. **Response**:
   - On success, read `document.pdf` into memory and send it using `res.send(buffer)` (or use `res.sendFile`). Since `backend-adapter.js` expects an ArrayBuffer when `response.ok`, `res.send(buffer)` with a generic OK status works.
   - On error, return JSON with the `document.log` contents or a timeout error message.
