# Plan: 04-02 (Wire SyncTeX UI events in the frontend)

## Objective
Enable double-clicking the PDF to jump to the corresponding code line by calling the `synctex` backend endpoint via the adapter.

## Tasks
1. **Update `backend-adapter.js`**:
   - In `invokeSyncTeX(pageNum, pdfX, pdfY)`, add the Tauri IPC call: `return await window.__TAURI__.core.invoke('synctex', { page: pageNum, x: pdfX, y: pdfY })`.
2. **Verify `main.js`**:
   - The PDF double-click handler in `main.js` already calls `window.BackendAdapter.invokeSyncTeX`. Make sure the coordinates sent matches the expected input of the `synctex` command, and it accurately parses the response `{ line: 12 }` to scroll the CodeMirror editor.
