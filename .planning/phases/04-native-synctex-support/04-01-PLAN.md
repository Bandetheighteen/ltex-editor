# Plan: 04-01 (Implement synctex Tauri command wrapping the CLI)

## Objective
Add a Tauri command that takes PDF page and coordinates, runs the `synctex` CLI utility, and parses its output to return the corresponding source code line.

## Tasks
1. **Implement `synctex` command in `lib.rs`**:
   - Create a `#[tauri::command] async fn synctex(page: u32, x: f32, y: f32) -> Result<SyncTexResponse, String>`.
   - The command will need to know where the compiled PDF and `.synctex.gz` files live. To do this, we need to adjust Phase 3's `compile_latex` to not use an ephemeral tempdir that deletes itself immediately, OR we need to save the `.synctex.gz` file somewhere persistent during compile. Let's create a dedicated persistent temporary workspace for the app (e.g., in the OS temp directory under `latex-editor-workspace`).
   - Run `std::process::Command::new("synctex")` with arguments `edit`, `-o`, `page:x:y:pdf_path`.
   - Parse the stdout from `synctex` to extract the `Line:` number.
2. **Define `SyncTexResponse`**:
   - Define a response struct: `#[derive(Serialize)] pub struct SyncTexResponse { line: Option<u32> }`.
3. **Register Command**:
   - Add the `synctex` function to the `invoke_handler` in `lib.rs`.
