# Plan: 05-01 (Scaffold Express.js server to serve the frontend)

## Objective
Create a fresh, lightweight Node.js Express server to serve the `public/` directory for browser-based access.

## Tasks
1. **Dependencies**:
   - Ensure `express` is installed (`npm install express`).
2. **Server Scaffold**:
   - Create or overwrite `server.js` at the project root.
   - Initialize an Express app that serves static files from `public/`.
   - Start the server on port 3000 (or via `process.env.PORT`).
   - Add graceful shutdown handling for `SIGINT` and `SIGTERM` to prevent port locking when stopping the server.
3. **Scripts**:
   - Update `package.json` to have a `"start": "node server.js"` script for easy launching.
